# Центр интимной эстетики

Статический сайт (HTML, CSS, JS без сборки).

Запуск локально:

```bash
python3 -m http.server 5173 --directory site
```

Открыть http://localhost:5173

- `site/index.html` — главная
- `site/directions.html` — выбор направления
- `site/bos.html` — БОС-терапия
- `site/soon.html` — заглушка для разделов без макета
- `site/js/main.js` — шапка, меню, футер, плашки направлений, анимации
- `site/css/style.css` — стили и дизайн-токены (градиенты направлений)
